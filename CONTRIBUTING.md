# Contributing to marten-core

Thanks for contributing. Keep pull requests focused and describe the problem, the approach, and the commands you used to verify the change.

- Format edited Go files with `gofmt`.
- Keep generated protobuf files aligned with their `.proto` sources when a protocol definition changes.
- Run the affected tests; use the commands in [README.md](README.md) for broader checks.
- Do not commit credentials, profiles, signing material, generated binaries, or locally supplied runtime artifacts.

Please discuss substantial changes in an issue before starting work. For security-sensitive reports, use the process in [SECURITY.md](SECURITY.md) rather than a public issue or pull request.
